# cccxa

כלי קונסולה ל-Windows שרץ ברקע ומתעד פעילות מקומית עבור סוכן AI מקומי שרץ על הנתונים שלך.
כל הנתונים נשמרים **מקומית בלבד** במחשב שלך ולא נשלחים לשום מקום.

מה נאסף:

- **צילומי מסך** ברזולציה נמוכה, במרווח דינאמי (ברירת מחדל: כל דקה), דחוסים כ-JPEG.
- **כתובות אתרים** מ-Chrome / Edge / Brave ודומיהם, כולל **גלישה בסתר ומצב אורח**.
- **היסטוריית גלישה קיימת** מיובאת מקבצי ה-History של הדפדפנים.
- **תוכנות** שנפתחות ונסגרות, **קבצים ומסמכים** שנפתחו, וה**חלון הפעיל** בכל רגע.
- **דשבורד HTML גרפי** עצמאי לתצוגה נוחה של הכל.

## הערה חשובה על שימוש אחראי וחוקי

הכלי מיועד להרצה על מחשב שבבעלותך. תיעוד של משתמשים אחרים במחשב (גם ממשתמש מנהל) כפוף לחוק,
ולעיתים מחייב יידוע ו/או הסכמה - תלוי בתחום השיפוט ובקשר ביניכם (למשל הורה/ילד קטין, מחשב חברה
בבעלותך עם מדיניות ידועה לעובדים וכו'). ודא שיש לך את הסמכות החוקית לכך. האחריות עליך.

יש מנגנון מובנה להחרגת משתמשים (למשל משתמש עבודה עם חומר רגיש) - ראה "סינון משתמשים".

## דרישות ובנייה

- Windows 10/11 (x64).
- .NET 8 SDK - **לבנייה בלבד**. הגרסה העצמאית שנוצרת אינה דורשת התקנת .NET על מחשב היעד.

### גרסה עצמאית (מומלץ) - כוללת את כל התלויות

```powershell
cd C:\dev\CCC\cccxa\installer
powershell -ExecutionPolicy Bypass -File .\publish.ps1
```

נוצר `dist\cccxa.exe` - קובץ יחיד שכולל את סביבת הריצה של .NET, SQLite, FlaUI וכל שאר התלויות.
אין צורך להתקין שום דבר על מחשב היעד.

> **נראות:** התוכנה מקומפלת כ-WinExe (תת-מערכת Windows) - במצב הרקע לא נוצרת קונסולה, אין חלון,
> ואין רישום בשורת המשימות או ב-Alt+Tab. היא נראית רק כתהליך ב-Task Manager. פקודות CLI (למטה)
> מתחברות לקונסולת הטרמינל שממנו הורצו כדי להציג פלט.

### בנייה רגילה (לפיתוח)

```powershell
dotnet build C:\dev\CCC\cccxa\cccxa.csproj -c Release
```

## מתקין שקט (מנהל -> כל המשתמשים)

יש להריץ **כמנהל**. המתקין מעתיק את התוכנה, מגדיר אחסון מרכזי, יוצר משימה מתוזמנת נסתרת שרצה
ברקע בכל התחברות משתמש (בהקשר המשתמש עצמו), ומוסיף קיצור לדשבורד בשולחן העבודה של המנהל.

```powershell
cd C:\dev\CCC\cccxa\installer

# התקנה בסיסית שקטה
powershell -ExecutionPolicy Bypass -File .\install.ps1

# לתעד רק משתמשים מסוימים
powershell -ExecutionPolicy Bypass -File .\install.ps1 -OnlyUsers alice,bob

# לא לתעד את משתמש העבודה (חומר רגיש של החברה)
powershell -ExecutionPolicy Bypass -File .\install.ps1 -ExcludeUsers work

# בלי אייקון בשולחן העבודה ובלי תיקייה בתפריט התחל
powershell -ExecutionPolicy Bypass -File .\install.ps1 -NoDesktopIcon -NoStartMenu
```

פרמטרים עיקריים:

| פרמטר | ברירת מחדל | תיאור |
|-------|-----------|-------|
| `-Source` | `..\dist` | מאיפה לקחת את cccxa.exe (פלט publish.ps1) |
| `-InstallDir` | `%ProgramFiles%\cccxa` | תיקיית התוכנה |
| `-StorageDir` | `%ProgramData%\cccxa` | תיקיית האחסון המרכזית |
| `-OnlyUsers` | (ריק) | תעד רק משתמשים אלה (גם ברמת המשימה המתוזמנת) |
| `-ExcludeUsers` | (ריק) | לעולם אל תתעד משתמשים אלה |
| `-NoDesktopIcon` | - | דלג על אייקון הדשבורד בשולחן העבודה |
| `-NoStartMenu` | - | דלג על תיקיית תפריט התחל |
| `-Quiet` | - | ללא פלט |

### הסרה

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1              # שומר את הנתונים
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1 -RemoveData  # מוחק גם את הנתונים
```

> למה משימה מתוזמנת ולא Windows Service: לכידת מסך ושורת כתובת דורשות ריצה **בתוך הסשן של המשתמש**.
> המשימה מוגדרת לרוץ בהתחברות כל משתמש (קבוצת Users, ללא הרשאות מנהל, נסתרת), וכך היא מתעדת את
> כל משתמש בסשן שלו. שירות שרץ כ-SYSTEM לא היה יכול לצלם את שולחן העבודה של המשתמש.

## סינון משתמשים

שני מנגנונים, ב-`appsettings.json` (או דרך פרמטרי המתקין):

```json
"OnlyUsers": ["alice", "bob"],
"ExcludeUsers": ["work"]
```

- `ExcludeUsers` - שמות משתמשים שלעולם לא יתועדו. גובר על הכל. זה הפתרון להחרגת משתמש עבודה.
- `OnlyUsers` - אם לא ריק, התיעוד יתבצע **רק** עבור משתמשים אלה.

הבדיקה מתבצעת בכל הפעלה: אם המשתמש הנוכחי אינו מורשה, התהליך יוצא מיד ואינו מתעד דבר.
בנוסף, כשמתקינים עם `-OnlyUsers`, המשימה המתוזמנת עצמה מוגבלת לאותם משתמשים (הגנה כפולה).

### דוגמה: מעקב רק אחרי משתמש בשם "משתמש ילדים" (עברית + רווח)

השם חייב להיות **שם החשבון המדויק** שמחזירה הפקודה `whoami` (ללא חלק הדומיין), לא שם התצוגה.

- במתקין הגרפי: בדף "User filtering", בתיבה "Record ONLY these users", הקלד `משתמש ילדים` בשורה נפרדת.
- ב-`install.ps1`:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\install.ps1 -OnlyUsers "משתמש ילדים"
  ```
- ידנית ב-`appsettings.json`:
  ```json
  "OnlyUsers": [ "משתמש ילדים" ],
  "ExcludeUsers": []
  ```

לתמיכה בכמה משתמשים: `-OnlyUsers "משתמש ילדים","דנה"`, או שורה לכל שם בתיבת המתקין.

### איך לדעת מה שם המשתמש המדויק

השם הנדרש הוא **שם החשבון (SAM)**, לא שם התצוגה ולא בהכרח שם התיקייה תחת `C:\Users`.
ההשוואה אינה תלוית רישיות (אותיות גדולות/קטנות לא משנות).

- **בסשן של אותו משתמש** (הכי מדויק) - הרץ אחת מהפקודות:
  ```powershell
  whoami            # מחזיר  COMPUTERNAME\username  - קח את החלק שאחרי ה-\
  echo $env:USERNAME
  ```
  ב-CMD רגיל: `echo %USERNAME%`.

- **מחשבון המנהל, בלי להיכנס למשתמש** - הצג את כל החשבונות המקומיים:
  ```powershell
  Get-LocalUser | Select-Object Name          # PowerShell
  ```
  או:
  ```cmd
  net user                                    # CMD - רשימת כל המשתמשים
  quser                                       # משתמשים המחוברים כרגע וסשן פעיל
  ```

- לחשבון **דומיין** יש להשתמש רק בחלק שאחרי ה-`\` (למשל מ-`CORP\shlomo` הזן `shlomo`).
  אם `whoami` מחזיר `pcname\shlomo`, הערך הנכון הוא `shlomo`.

## דשבורד גרפי (HTML)

דשבורד בעיצוב בסגנון shadcn/ui, עם תמיכה מלאה ב-RTL ובשתי שפות (עברית/אנגלית - ברירת מחדל לפי
שפת הדפדפן, וכפתור החלפה), מצב בהיר/כהה, ובורר משתמשים. **החלוקה היא לפי משתמש** - כל משתמש
בנפרד, עם תג "משתמש: <שם>".

הקיצור **"cccxa - Activity Dashboard"** בשולחן העבודה מריץ את מצב `serve`:

```powershell
cccxa.exe serve [port]    # דשבורד חי + ממשק הגדרות (שרת מקומי על-פי דרישה)
```

- שרת מקומי קצר-חיים על `http://127.0.0.1` (loopback בלבד) - **לא תהליך רקע קבוע**. הדף שולח
  פינג כל 15 שניות, וכשסוגרים אותו (או אחרי ~45 שניות ללא פינג) השרת נסגר אוטומטית.
- **ריענון הדף מציג נתונים עדכניים** (הדף נבנה מחדש מה-DB בכל טעינה).
- צילומי המסך מוגשים דרך השרת, כך שהם מוצגים תמיד.

הדשבורד כולל: כרטיסי סיכום, גרף פעילות לפי שעה, אתרים ותוכנות מובילים, **כל היסטוריית הגלישה**
(עם עמודות דפדפן + תג "בסתר"), **כל היסטוריית השימוש בתוכנות**, כל הקבצים - הכל עם חיפוש ודפדוף,
וגלריית צילומי מסך.

### ממשק הגדרות (לשונית "הגדרות")

בדשבורד החי יש לשונית **הגדרות** לצפייה ועריכה של כל ההגדרות (צילומי מסך, לכידה, מחיקה אוטומטית,
ייבוא היסטוריה, תדירות דגימה, סינון משתמשים, ומתקדם). כפתור **שמור** כותב ישירות ל-`appsettings.json`
והשינוי נכנס לתוקף מיד (hot reload). את סינון המשתמשים אפשר לערוך כאן ישירות (שורה לכל שם, כולל עברית).

### דשבורד סטטי לשיתוף (קובץ בודד)

לצורך שיתוף תמונת מצב כקובץ יחיד (בלי שרת), עדיין קיימות הפקודות:

```powershell
cccxa.exe report          # קובץ HTML למשתמש הנוכחי, נתונים מוטמעים
cccxa.exe report-all      # קובץ HTML לכל המשתמשים
```

בקובץ הסטטי הנתונים מוטמעים והכל מוצג ללא ייבוא; עריכת ההגדרות אינה זמינה (רק בדשבורד החי),
וצילומי המסך נטענים דרך `file://`.

## היכן נשמרים הנתונים

- **התקנה מרובת-משתמשים** (דרך המתקין): `%ProgramData%\cccxa\data\<username>\`
  המנהל יכול לקרוא את כל המשתמשים. הדשבורד המשולב נוצר תחת `%ProgramData%\cccxa\dashboard.html`.
- **הרצה בודדת ללא התקנה**: `%LOCALAPPDATA%\cccxa\`

```
cccxa\
  data\
    alice\
      cccxa.db                 # מסד SQLite: events + screenshots
      screenshots\2026-08-04\14-05-00.jpg
      history_state.json
    bob\
      ...
  dashboard.html               # הדשבורד המשולב
```

### סכימת מסד הנתונים

טבלת `events`: `ts, type, app, title, url, detail`
כאשר `type` הוא אחד מ: `foreground` / `browser_url` / `history_visit` / `process_start` /
`process_stop` / `recent_file`.

טבלת `screenshots`: `ts, path, width, height, bytes`.

## ייצוא לשיתוף עם AI (JSONL, בלי שרתים)

```powershell
cccxa.exe export                 # ייצוא המשתמש הנוכחי
cccxa.exe export C:\out          # ליעד מסוים
cccxa.exe export-all             # ייצוא כל המשתמשים (למנהל), תיקייה לכל משתמש
```

נוצרים `events.jsonl`, `browsing.jsonl`, `screenshots.jsonl` - שורת JSON אחת לכל רשומה,
מוכן להזנה ישירה לכל כלי/מודל מקומי, או לשאילתה ישירה על ה-SQLite.

> מכיוון שהתוכנה היא WinExe, בהרצת פקודה מטרמינל ה-shell עלול להחזיר את הפרומפט לפני שהפקודה
> מסתיימת (הקבצים נוצרים כרגיל). להמתנה מסודרת עם פלט:
> `Start-Process .\cccxa.exe -ArgumentList export -Wait -NoNewWindow`

## הגדרות (דינאמיות)

הכל ב-`appsettings.json` שליד ה-exe. **שינויים נטענים בזמן ריצה** - אין צורך להפעיל מחדש.

| מפתח | ברירת מחדל | תיאור |
|------|-----------|-------|
| `StorageRoot` | `%LOCALAPPDATA%\cccxa` | תיקיית היעד (תומך %ENV% כולל %USERNAME%) |
| `OnlyUsers` | `[]` | תעד רק משתמשים אלה |
| `ExcludeUsers` | `[]` | לעולם אל תתעד משתמשים אלה |
| `Screenshot.Enabled` | `true` | הפעלת צילומי מסך |
| `Screenshot.IntervalSeconds` | `60` | מרווח בין צילומים (מינימום 5) |
| `Screenshot.Scale` | `0.5` | גורם הקטנה |
| `Screenshot.MaxWidth` | `1600` | רוחב מרבי בפיקסלים (0 = ללא) |
| `Screenshot.JpegQuality` | `40` | איכות JPEG 10-95 |
| `Screenshot.SkipWhenIdleSeconds` | `120` | דלג על צילום אם אין פעילות מעל N שניות (0 = תמיד) |
| `ScreenshotRetentionDays` | `7` | מחיקה אוטומטית של צילומי מסך ישנים מ-N ימים (0 = לשמור לתמיד) |
| `DataRetentionDays` | `30` | מחיקה אוטומטית של שאר הנתונים ישנים מ-N ימים (0 = לשמור לתמיד) |
| `RetentionCheckHours` | `6` | כל כמה שעות לבצע את בדיקת המחיקה |
| `CaptureBrowserUrls` | `true` | לכידת כתובות חיות (כולל בסתר/אורח) |
| `CaptureProcesses` | `true` | תוכנות שנפתחות/נסגרות |
| `CaptureForegroundWindows` | `true` | מעקב חלון פעיל |
| `CaptureRecentFiles` | `true` | קבצים/מסמכים שנפתחו |
| `ImportBrowserHistory` | `true` | ייבוא היסטוריית גלישה קיימת |
| `HistoryImportIntervalMinutes` | `5` | כל כמה דקות לייבא היסטוריה |
| `ForegroundPollMs` | `1000` | תדירות דגימת חלון פעיל |
| `ProcessPollMs` | `3000` | תדירות דגימת תהליכים |
| `BrowserProcessNames` | chrome, msedge, brave, opera, vivaldi, chromium | אילו תהליכים נחשבים דפדפן |
| `BrowserAddressBarNames` | ראה קובץ | שם שורת הכתובת ב-UI Automation (תלוי שפה) |

### אם כתובות אתרים לא נלכדות

לכידת ה-URL קוראת את שורת הכתובת דרך UI Automation, ושם הרכיב תלוי בשפת המערכת. אם הכתובות
לא נשמרות, מצא את השם המדויק (למשל עם Accessibility Insights) והוסף אותו ל-`BrowserAddressBarNames`.
יש כבר fallback שמנסה לזהות שורת כתובת גם ללא שם מדויק.

## מחיקה אוטומטית (retention)

כדי לא לצבור נתונים לאורך זמן, רץ ברקע שירות מחיקה שמסיר אוטומטית:

- **צילומי מסך** ישנים מ-`ScreenshotRetentionDays` ימים (ברירת מחדל 7) - כולל קובצי ה-JPEG בדיסק.
- **שאר הנתונים** (אירועי גלישה/תוכנות/קבצים) ישנים מ-`DataRetentionDays` ימים (ברירת מחדל 30).

הבדיקה רצה כל `RetentionCheckHours` שעות (ברירת מחדל 6) וגם פעם אחת בהפעלה. הערכים **דינאמיים** -
שינוי ב-`appsettings.json` נכנס לתוקף בלי הפעלה מחדש. ערך `0` בקטגוריה = שמירה לתמיד (ללא מחיקה).

## עומס על המערכת

צילום מוקטן + JPEG נמוך (~20-40KB), קריאת URL רק כשהחלון משתנה עם דה-דופ, דגימת תהליכים כל 3 שניות,
מעקב קבצים מבוסס-אירועים, ודילוג אוטומטי על צילום כשאין פעילות. להקלה נוספת: הגדל `IntervalSeconds`,
הקטן `Scale`/`MaxWidth`, או כבה אוספים מיותרים.

## גלישה בסתר / מצב אורח

גלישה בסתר ואורח אינן נשמרות בקובץ ההיסטוריה, ולכן לא ניתן לייבא אותן. במקום זאת, כל עוד החלון פעיל,
`cccxa` קורא את הכתובת חי משורת הכתובת ושומר אותה. שתי הדרכים (ייבוא + קריאה חיה) עובדות יחד.
